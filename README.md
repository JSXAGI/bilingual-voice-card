# 🇺🇸🇯🇵 JA-EN Bilingual Voice Card

A beautiful, high-performance Progressive Web App (PWA) designed for mastering essential everyday English phrases with native audio playback.

## 🚀 Features
- **Bilingual TTS (Text-to-Speech):** Crystal clear audio in both American English and Japanese.
- **Smart Filter:** Sort cards by length (Short / Long phrases) or Shuffle them instantly.
- **Auto-Advance Switch:** Hands-free learning mode that automatically flips to the next card after reading.
- **Instant Search:** Find any phrase instantly by typing keywords.
- **PWA Ready:** Install it directly to your smartphone's home screen and learn anytime, anywhere!

## 📱 How to Install (PWA)
1. Open the deployed URL in your smartphone browser (Safari on iOS / Chrome on Android).
2. Tap the **Share** or **Menu** button.
3. Select **"Add to Home Screen"**.
4. The app icon will appear on your screen, ready to launch in full-screen standalone mode!
